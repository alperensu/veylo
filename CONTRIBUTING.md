# Contributing

Commands: README.md; approved scope: docs/PLAN.md. Keep audio callbacks free of
allocation/locks/files. Update C++/C# ABI layouts together with version/size tests.
Preserve third-party licenses, model provenance/checksums when upgrading.

recordings/device state/tools/builds/secrets. Run tests and inspect actual TR/EN
UI, compact layout, keyboard labels. Separate simulations from live game/audio
evidence in validation reports.
