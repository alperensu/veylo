# GitHub görsel varlıkları

- `veylo-banner*.svg`: Veylo'nun uygulamada kullanılan özgün ses çubuğu simgesiyle hazırlanmış statik vektör kapaklar. Türkçe/İngilizce ve dar ekran varyantları vardır. Script, dış font veya uzak kaynak içermez; kaynak koduyla aynı MIT lisansı geçerlidir.
- `overview.png`, `profiles.png`, `calibration.png`: Veylo 0.7.5-dev kod ağacının mevcut kontrollü WPF arayüz testlerinden, değiştirilmeden alınmıştır. `artifacts/ui/design-tr-1160-Overview-.png`, `design-tr-1160-Profiles-.png` ve `personal-start-tr.png` kaynaklarıdır.

Görüntüler gerçek uygulama arayüzünü gösterir; test cihazı, profil ve seviye değerleri örnektir. Gerçek mikrofon ölçümü, kullanıcı kaydı veya performans kanıtı değildir. Kişisel ses veya cihaz kimliği içermez.

Uygulama arayüzü değiştiğinde görüntüleri aynı kontrollü test yolu üzerinden güncelle ve [ana README](../../README.md) ile İngilizce sayfanın alt metinlerini kontrol et.
